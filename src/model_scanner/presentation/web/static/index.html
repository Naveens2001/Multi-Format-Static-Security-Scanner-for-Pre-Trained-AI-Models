Methodology & coverage

✓ What was analysed

  • Pickle opcode streams, disassembled symbolically — never executed or deserialized
  • PyTorch ZIP archives inspected as containers; archive/data.pkl analysed as pickle
  • SafeTensors headers and metadata key–value pairs
  • GGUF metadata sections, key–value pairs and offset tables
  • Cross-format structural anomalies — magic-byte and extension conflicts

! Scope & limitations

  • Detection is pattern-based and static — there is no behavioural analysis
  • Model weights and tensor data are never loaded into memory
  • Zero runtime dependencies — pure Python standard library engine
  • Legacy non-ZIP PyTorch checkpoints are reported UNSUPPORTED, not analysed
  • Dataset repositories are out of scope — model files only

Static analysis disclaimer. Evidence represents security-relevant structures observed during static inspection. It does not constitute proof of successful exploitation, and a clean result is not a guarantee of safety.
